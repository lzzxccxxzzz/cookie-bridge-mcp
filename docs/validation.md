## 实际走过的链路

被测动作全部由真实 MCP 客户端发出，经过 stdio 服务、HTTP 队列和游戏执行器。断言读取游戏原生状态，而不是仅相信 MCP 回执。CDP 用于准备夹具和独立观察，不代替被测动作。

测试进程使用独立游戏副本、存档、用户资料、数据库和动作日志，跳过 Steam SDK 初始化。原版游戏资产没有上传。实机测试入口要求 `test_mode=true`，并确认 CDP 页面位于相同测试根目录。

## 恢复与协议

真实退出并重新启动测试游戏后确认：已完成回执保留；派发后丢失结果的动作变为 `indeterminate` 且不重放；未派发项恢复并仅点击一次；旧 UI 引用和旧 prompt token 被拒绝。

离线测试还覆盖过期、容量限制、FIFO、回执幂等与批量验证、迟到回执、损坏日志拒绝启动、敏感参数脱敏，以及通过本地 HTTP 模拟服务验证 MCP 版本不匹配/过期状态错误传播。模拟服务测试不冒充实机结果。

## 正式部署

原有两个存档文件在部署前另行备份；复制后和安装后均校验 SHA-256 一致。安装器另外保存旧桥接文件。正式游戏使用原存档，**没有执行清档、升天、资源注入或被测玩法动作**；部署后的检查只读取 MCP 状态、目录和文档页。

本机直接启动时在 Steam 接口初始化附近退出；启动 Steam 客户端后，正式进程正常运行，3.1.0 服务及渲染器检查通过。没有修改 Steam 原生库或绕过账户验证。

## 不应从这些结果推导出的结论

- 101 工具全通过，不等于穷尽全部游戏状态、每个升级组合、所有偏好或所有成就。
- 10K 的饼干来自真实点击和生产，但黄金饼干是受控生成，不是等待自然随机刷新。
- 后期测试使用合成资源、解锁、成熟度、计时器和目标；不代表无作弊自然通关。
- 全部升级类型有代表性测试，不是购买目录里的每一个升级；双光环测试不是逐个测试全部光环效果。
- 验证了挑战模式的选择，转生实测为普通模式；没有完成 Born again 挑战通关。
- 随机法术失败、突变、掉落和季节奖励保留原生规则，不承诺特定随机结果。
- UI 拖放和指针验证了代表性控件，不保证每种画布手势。Steam/系统对话框、第三方 Mod API 和游戏源代码里的未实现占位功能仍排除。
